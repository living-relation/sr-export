# Usage

Once the add-in is installed and running in Fusion, use it from the Fusion interface to export the active design in multiple formats in one click.

The add-in code is not in this repository yet, so the steps below stay at a high level.

## Before you start

1. Install the add-in as described in [Install](install.md).
2. Open the Fusion design you want to work with.
